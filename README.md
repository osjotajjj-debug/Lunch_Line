# Sistema de Fila do Almoço

## Instalação

1. Instale as dependências:
```bash
pip install -r requirements.txt
```

2. Execute o programa:
```bash
python main.py
```

## Configuração

Edite o arquivo `config.yaml` para personalizar:
- Turmas por dia da semana
- Duração do timer
- Pausa entre chamadas

## Uso

1. Selecione o dia da semana
2. Clique em "INICIAR"
3. O sistema automaticamente chamará as turmas
4. Use "CHAMAR" para avançar manualmente
5. Use "PARAR" para pausar o timer

## Funcionalidades

- Timer automático com contagem regressiva
- Pausa configurável entre chamadas (para alunos se locomoverem)
- Duas vozes distintas para cada fila
- Interface visual para TVs
- Configuração por dia da semana
